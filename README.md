# Cyberian ThreatShield

Detection Engineering & Threat Hunting Project

## Objective

Develop evidence-based security detections using Windows telemetry,
Sigma and MITRE ATT&CK.

## Technology

- Kali Linux
- Python
- pandas
- python-evtx
- Sigma / pySigma
- MITRE ATT&CK
- EVTX security telemetry
- Git

## Project Pipeline

EVTX
→ Parsing
→ Normalization
→ Data Dictionary
→ Detection Engineering
→ Sigma
→ ATT&CK
→ Threat Hunting
→ Incident Investigation
→ IR Playbooks

## Evidence

The project uses public security telemetry rather than fabricated logs.
