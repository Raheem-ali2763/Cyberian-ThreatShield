# Cyberian ThreatShield Methodology

## 1. Telemetry Acquisition

Use public security datasets and preserve original evidence.

## 2. Normalization

Parse EVTX telemetry and normalize events into JSONL.

## 3. Detection Engineering

Create Sigma rules using observed telemetry fields.

## 4. ATT&CK Mapping

Map detections to relevant MITRE ATT&CK techniques.

## 5. Threat Hunting

Develop hypotheses and search telemetry for supporting evidence.

## 6. Incident Investigation

Build timelines from raw evidence and document limitations.

## 7. Tuning

Review false positives and improve detection logic.

## 8. Reproducibility

Maintain scripts, datasets, documentation and version-controlled
artifacts.
