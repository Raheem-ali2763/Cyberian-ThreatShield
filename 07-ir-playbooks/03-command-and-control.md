# IR Playbook - Command and Control

## Trigger

Suspicious outbound communication or beaconing detection.

## Steps

1. Validate destination.
2. Identify affected endpoint.
3. Review DNS and network telemetry.
4. Review process tree.
5. Check for persistence.
6. Isolate endpoint if required.
7. Block confirmed malicious infrastructure according to policy.
8. Search for related IOCs.
9. Preserve evidence.
10. Document eradication and recovery.
